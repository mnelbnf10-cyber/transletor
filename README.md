# Instant Translator APK

تطبيق Android تجريبي للترجمة الصوتية الفورية إلى العربية.

## ماذا يفعل؟
- يعمل كـ Foreground Service باستخدام الميكروفون.
- يحاول اكتشاف لغة الكلام تلقائياً على Android 14+ باستخدام SpeechRecognizer language detection.
- يحول الكلام إلى نص.
- يترجم النص إلى العربية باستخدام ML Kit Translation.
- ينطق الترجمة عبر مخرج الصوت الحالي، بما في ذلك سماعة Bluetooth/Anker إذا كانت متصلة.
- يعيد تشغيل جلسة الاستماع تلقائياً بعد انتهاء كل مقطع.

## GitHub Actions
ارفع المشروع إلى GitHub، ثم افتح Actions وشغل **Build APK**. سيتم رفع `app-release.apk` كـ Artifact.

## ملاحظات مهمة
- أول استخدام للترجمة قد يحتاج تنزيل نماذج ML Kit للغات المطلوبة.
- التعرف الصوتي يعتمد على SpeechRecognizer المتوفر في الجهاز؛ قد يحتاج الإنترنت بحسب محرك التعرف المثبت.
- Android يفرض إشعار Foreground Service أثناء استخدام الميكروفون.
- على Android 14+ يجب تشغيل الخدمة من واجهة التطبيق وهي ظاهرة للمستخدم قبل ترك التطبيق للخلفية.
- هذا الإصدار يستهدف العربية كهدف ثابت.
